# Advanced Rocketry - Expanded

A maintained fork of [**Advanced Rocketry**](https://github.com/Advanced-Rocketry/AdvancedRocketry) and [**Advanced Rocketry - Reworked**](https://github.com/kaduvill/AdvancedRocketry) for **Minecraft 1.12.2**.

This project continues development of the original mod with ongoing bug fixes, improvements, and quality-of-life updates for modern 1.12.2 modpacks. On top of that, this project will be adding new features.

## About

**Advanced Rocketry - Reworked** exists to keep Advanced Rocketry alive and actively maintained for the community.

The goal of this fork is to improve stability, expand usability for both players and pack developers, and continue refining one of the most ambitious space and progression mods for Minecraft 1.12.2.
